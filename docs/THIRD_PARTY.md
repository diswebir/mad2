# حقوق اجزای ثالث

**سازندهٔ سامانه:** مدرسه‌یار محصول **شرکت دیس وب** است — <https://disweb.ir>.

فونت وزیرمتن مطابق SIL Open Font License 1.1، React و ReactDOM مطابق MIT و آیکون‌های Lucide مطابق ISC در این برنامه استفاده شده‌اند. متن حقوق و مجوز آن‌ها در پوشه `docs/licenses` همراه بستهٔ نصب قرار دارد. فونت با نام اصلی و بدون تغییر توزیع می‌شود.

سایر وابستگی‌های Node.js هنگام `npm ci` با فایل مجوز خود از رجیستری نصب می‌شوند؛ نسخه‌های دقیق در `package-lock.json` هستند. این اعلان به‌خودی‌خود مجوز جدیدی برای کد اختصاصی صاحب مخزن تعیین نمی‌کند.
