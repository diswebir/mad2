# فعال‌سازی لایسنس برای یک مدرسه — راهنمای خیلی ساده

این راهنما برای کسی نوشته شده که برنامه‌نویس نیست. فقط سه بار «کپی و پیست» لازم است. کل کار حدود ۵ دقیقه طول می‌کشی.

> **ماجرا مثل قفل و کلید است:** یک «قفل» داری که در نسخهٔ فروشی می‌گذاری (کلید عمومی) و یک «کلید» که فقط پیش خودت می‌ماند (کلید خصوصی). برای هر مدرسه یک «برگهٔ اجازهٔ امضاشده» می‌نویسی (فایل لایسنس) و به مدرسه می‌دهی. مدرسه برگه را کنار سامانه می‌گذارد و سامانه خودش امضایش را با قفل چک می‌کند. **اینترنت هم لازم نیست.**

---

## بخش ۱ — یک بار برای همیشه (۵ دقیقه، فقط بار اول)

### قدم ۱: برنامهٔ Node را روی کامپیوتر خودت نصب کن

برو به `nodejs.org` و دکمهٔ سبز **LTS** را دانلود و نصب کن (مثل نصب هر برنامهٔ دیگر). همین!

### قدم ۲: پوشهٔ سامانه را باز کن

پوشهٔ `mad2` (همین پروژه) را باز کن. در نوار آدرس بالای پنجره بنویس `cmd` (ویندوز) یا `Terminal` را باز کن و برو داخل پوشه. کارِ ساده‌تر: در پوشه، **راست‌کلیک → Open in Terminal**.

### قدم ۳: دو خط آماده‌سازی

این دو خط را کپی کن و در آن پنجرهٔ سیاه پیست کن و Enter بزن (بار اول کمی طول می‌کشد):

```bash
npm ci
npm run license:make
```

خط دوم یک برنامهٔ فارسی باز می‌کند که از تو سؤال می‌پرسد. اگر **اولین بار** است، خودش «کلیدهای فروشنده» را می‌سازد و در پوشهٔ `license-keys` می‌گذارد:

| فایل                               | معنی          | با آن چه کنم؟                                               |
| ---------------------------------- | ------------- | ----------------------------------------------------------- |
| `license-keys/license-private.pem` | **کلید شما**  | پیش خودت نگه دار. به هیچ‌کس نده. در واتساپ/ایمیل/گیت نگذار. |
| `license-keys/license-public.pem`  | **قفل عمومی** | خودکار داخل بستهٔ فروشی می‌رود. کاری با آن نداری.           |

از این به بعد این جادوگر (خط `npm run license:make`) ابزار کار روزمرهٔ توست. حالا `Ctrl+C` بزن تا بس شود؛ در بخش ۲ همه‌چیز را با هم می‌سازیم.

> اگر `npm ci` خطا داد: مطمئن شو Node نصب شده (`node -v` را در همان پنجره بزن) و اینترنت وصل است.

## بخش ۲ — برای هر مدرسه (۱ دقیقه)

### قدم ۱: جادوگر را باز کن

```bash
npm run license:make
```

### قدم ۲: به ۵ سؤال جواب بده

1. **نام مدرسه** → مثلاً `دبستان شهید رجایی` (همین روی لایسنس و در پنل مدرسه دیده می‌شود).
2. **سریال** → Enter بزن، خودش یک شماره می‌سازد (مثل `MY-1405-3726`).
3. **بسته** → شماره بزن: `1` پایه، `2` استاندارد (پایه+مالی+کتابخانه+گزارش‌ها)، `3` کامل، `4` خودم انتخاب می‌کنم (شمارهٔ ماژول‌ها را با کاما مثل `1,3` بنویس).
4. **یادداشت** → اختیاری؛ می‌توانی خالی بگذاری.
5. **مادام‌العمر؟** → `بله` بزن.

### قدم ۳: فایل آماده است

جادوگر یک فایل می‌سازد، مثلاً:

```
license-keys/MY-1405-3726.json
```

و پایینش، **متن آماده‌ای برای فرستادن به مدرسه** چاپ می‌کند. آن متن و فایل را برای مدرسه بفرست. تمام!

### قدم ۴ (مهم): بستهٔ فروشی را با همان قفل عمومی بساز

پیش از ارسال بسته به مدرسه، یک بار این را بزن:

```bash
npm run package:cpanel
```

این دستور «قفل عمومی» تو را **خودکار داخل بسته** می‌گذارد؛ پس مشتری هیچ فایل کدی را دست نمی‌زند. اگر این کار را نکنی، بسته بدون قفل ساخته می‌شود و مدرسه باید یک خط اضافه وارد کند (در بخش ۴ توضیح داده شده).

بستهٔ آماده: `artifacts/madresehyar-cpanel.zip` — همین را همراه فایل لایسنس بفرست.

## بخش ۳ — مدرسه چه کاری می‌کند؟ (سه کار، بدون کدنویسی)

به مدرسه همین سه خط را بفرست:

1. **فایل لایسنس** (`MY-1405-3726.json`) را در پوشهٔ دادهٔ سامانه بگذارید و نامش را دقیقاً بگذارید: **`license.json`**
   (پوشهٔ داده همان `DATA_DIR` است؛ مثلاً `/home/CPANEL_USER/madresehyar-data`).
2. در فایل تنظیمات (`.env`) یک خط اضافه کنند:

   ```dotenv
   LICENSE_MODE=on
   ```

3. از پنل هاست (Setup Node.js App) دکمهٔ **Restart** را بزنند.

### چطور مطمئن شویم فعال شد؟

در سامانه به **تنظیمات → وضعیت سرویس** برو. باید کارت لایسنس را ببینی: **نام مدرسه**، **سریال** و **تعداد ماژول‌های فعال**.

- ماژول‌هایی که فروخته‌ای: باز و معمولی.
- ماژول‌هایی که نفروخته‌ای: در صفحهٔ «ماژول‌ها» با برچسب **«خریدنی»** و سوییچ قفل‌شده.
- اگر کسی آدرس آن ماژول را مستقیم بزند، پیام «این بخش در لایسنس این مدرسه فعال نشده است» را می‌بیند.

## بخش ۴ — اگر جایی گیر کردی

| مشکل                                                           | کار ساده                                                                                                                                                        |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| جادوگر می‌گوید کلید ساخته شد، ولی نمی‌دانم کدام فایل را بفرستم | فایل `license-keys/MY-….json` (تنها فایلی که اسمش با `MY-` شروع می‌شود).                                                                                        |
| از پوشهٔ `license-keys` چیزی گم شد                             | اگر **کلید خصوصی** گم شد، دیگر نمی‌توانی لایسنس‌های قبلی را تمدید کنی؛ از پشتیبان همان پوشه استفاده کن. اگر فقط فایل یک مدرسه گم شد، با همان سریال دوباره بساز. |
| مدرسه می‌گوید «بدون لایسنس» است                                | سه چیز را چک کن: نام فایل دقیقاً `license.json` باشد؛ داخل پوشهٔ **داده** باشد نه پوشهٔ برنامه؛ `LICENSE_MODE=on` در `.env` باشد؛ و Restart شده باشد.           |
| مدرسه می‌گوید «امضا مطابقت ندارد»                              | بستهٔ فروشی با قفل عمومی دیگری ساخته شده. بسته را با `npm run package:cpanel` (وقتی `license-keys` پیش توست) **دوباره بساز** و بفرست.                           |
| مدرسه می‌گوید ماژول فلان قفل است ولی خریده                     | فایل لایسنس تازه با همان سریال بساز و آن ماژول را هم انتخاب کن؛ روی هاست جای‌گزین کن و Restart. **داده‌ای پاک نمی‌شود.**                                        |
| می‌خواهم ببینم لایسنس یک مدرسه سالم است یا نه                  | `npm run license:inspect -- --license ./license-keys/MY-….json`                                                                                                 |
| می‌خواهم لیست ماژول‌ها و قیمت‌گذاری را ببینم                   | `npm run license:list` و فایل `docs/LICENSING.md`                                                                                                               |
| مدرسه اشتباهی روی دموی نمایشی نصب کرده                         | به [docs/CPANEL-INSTALL.md](CPANEL-INSTALL.md) بخش «تبدیل نصب دمو به نصب واقعی» نگاه کن.                                                                        |

## بخش ۵ — قانون طلایی (حفظ و نگهداری)

1. **پوشهٔ `license-keys` را پشتیبان بگیر** (فلش + ایمیل شخصی خودت). این پوشه = کل فروش شما.
2. کلید خصوصی را **هرگز** برای مشتری نفرست؛ فقط فایل `MY-….json`.
3. برای فروش ماژول بعدی به همان مدرسه: جادوگر را باز کن، **همان سریال قبلی** را بده، ماژول‌های قبلی + جدید را انتخاب کن، فایل تازه بده.
4. برای شعبهٔ دوم همان مدرسه: سریال تازه بساز (لایسنس جدا) و در جدول دفتر لایسنس ثبت کن.
5. در گیت (Git) پوشهٔ `license-keys` را کامیت نکن — در `.gitignore` مسدود شده و همین‌طور بگذار.

جزئیات بیشتر (قیمت‌گذاری، قرارداد، قالب پیشنهاد): [docs/LICENSING.md](LICENSING.md)
